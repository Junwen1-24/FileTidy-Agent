# FileTidy Agent

FileTidy Agent 是一个可实际运行的本地文件整理 MVP。它扫描用户指定目录，以文件类型、名称、一级目录和修改时间生成可解释标签；用户确认后可预览并真实移动文件，之后还能一键撤销。

## 当前能力

- 扫描真实本地目录，自动生成分类、活跃度、截图、临时文件和项目标签。
- 展示每个标签的判断理由，支持编辑和批量确认。
- 按文件名、标签、确认状态和整理状态筛选。
- 整理前预览来源与目标，移动到根目录下的 `整理结果/`。
- 同名文件自动追加序号，不覆盖已有文件。
- 操作历史真实持久化，支持将整批文件撤回原位置。
- 内置 8 个种子文件，首次启动即可演示完整流程。
- 提供加载、成功、错误和空状态。

完整范围与验收定义见 `docs/PRD.md`。

## 技术方案

- 运行时：Node.js 18.16+
- 后端：Node 内置 HTTP 服务，无第三方运行依赖
- 前端：原生 HTML、CSS、JavaScript
- 数据：本地 JSON 状态文件，原子写入
- 测试：Node 内置 `node:test`

服务默认仅监听 `127.0.0.1`。扫描、标签和移动都在本机完成，不上传文件或文件内容。

## 从零启动

### 1. 环境要求

- Node.js `>= 18.16`
- npm `>= 9.5`（随 Node 安装即可）

### 2. 安装

项目没有第三方依赖，仍建议执行安装命令以校验 Node 版本并生成一致的 npm 环境：

```bash
npm install
```

### 3. 配置（可选）

应用不依赖必填环境变量。可参考 `.env.example` 直接在启动命令前设置：

```bash
PORT=4310 FILETIDY_MAX_FILES=1000 npm start
```

支持的变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 监听地址；不建议改为公网地址 |
| `PORT` | `4310` | 服务端口 |
| `FILETIDY_DATA_DIR` | `.filetidy-data` | 设置、标签、历史与演示工作区目录 |
| `FILETIDY_MAX_FILES` | `1000` | 单次最大扫描文件数 |
| `FILETIDY_MAX_DEPTH` | `8` | 最大递归层级 |

### 4. 启动

```bash
npm start
```

浏览器打开：`http://127.0.0.1:4310`

首次启动会在 `.filetidy-data/demo-workspace` 创建并扫描 8 个演示文件。无需配置真实目录即可体验。

开发时可使用自动重启：

```bash
npm run dev
```

## 演示流程

1. 启动后查看自动扫描出的演示文件和建议标签。
2. 勾选一个或多个文件，点击“确认建议标签”。
3. 也可以直接修改“已确认标签”输入框，移开焦点后保存。
4. 点击“预览并整理”，检查每个文件的来源和目标。
5. 确认整理后，文件会真实移动到演示工作区的 `整理结果/`。
6. 打开左侧“操作记录”，点击“撤销移动”，文件恢复到原位置。
7. 点击“重置演示数据”可随时恢复初始演示环境。

要整理自己的文件，请在“选择整理目录”输入绝对路径并保存。建议先对测试目录体验；MVP 不执行删除，但会真实移动所选文件。

## 数据与初始化

无需数据库服务或 migration。状态文件在：

```text
.filetidy-data/state.json
```

手动重建演示数据：

```bash
npm run seed
```

如果设置了 `FILETIDY_DATA_DIR`，状态和演示工作区会写入指定位置。

## 验证与构建

运行全量检查：

```bash
npm run verify
```

也可以分别执行：

```bash
npm run lint
npm run check
npm test
npm run build
```

`npm run build` 会生成 `dist/`。构建结果不需要额外安装依赖，可进入目录启动：

```bash
cd dist
npm start
```

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| GET | `/api/state` | 获取当前完整工作台状态 |
| POST | `/api/settings` | 设置目录，body: `{ "rootPath": "..." }` |
| POST | `/api/demo/reset` | 重置并扫描演示数据 |
| POST | `/api/scan` | 扫描当前目录 |
| PATCH | `/api/files/:id/tags` | 保存标签，body: `{ "tags": [] }` |
| POST | `/api/files/bulk-confirm` | 批量采纳建议 |
| POST | `/api/organize/preview` | 预览移动 |
| POST | `/api/organize/execute` | 执行移动 |
| POST | `/api/operations/:id/undo` | 撤销一次整理 |

## 安全边界与限制

- MVP 是本地 Web 应用，不是已签名的桌面安装包。
- “使用情况”当前以修改时间近似，不代表操作系统真实打开频次。
- 跳过隐藏文件和符号链接，不自动删除任何文件。
- 文件仅能移动到当前扫描根目录内，服务端会校验来源与目标路径。
- 撤销时若原位置已有同名文件，系统会停止并提示，不覆盖文件。
- JSON 数据层面向个人和小规模目录；后续大规模版本建议迁移 SQLite。
